# xushi-ai

# 项目简介
项目名称：叙事表达系统

项目解决的具体问题：
1. 解决通用大模型在企业场景中“知识不准、上下文不稳、工具不受控、链路不可观测”的问题。
2. 解决多数据源融合难题：会话历史、知识库、网页搜索、附件内容、工具结果需要统一编排。
3. 解决业务落地难题：从 Demo 级对话升级到可审计、可回放、可统计、可运营的线上系统。
4. 解决记忆连续性问题：构建“短期记忆 + 长期记忆”双层机制，短期记忆按语义与预算动态裁剪，长期记忆按会话主题异步沉淀并在新轮次自动注入。
5. 解决长上下文成本与稳定性问题：实现分层 token 预算（历史消息/附件/RAG/工具消息/技能/记忆），超限时按优先级自动降载，避免请求超长失败。
6. 解决工具调用失控问题：建立工具循环上限、结果反思提示、失败分级与终止策略，减少重复调用与无效推理。
7. 解决多模态文件理解难问题：支持 Office/PDF/图片/视频解析，结合 OCR、图像理解与精确内容增强，提升复杂附件场景可用性。
8. 解决流式场景中断一致性问题：补齐中断状态、工具轨迹、消息上下文与后处理入库，保障用户体验与数据一致性。

落地效果：
1. 入选中央网信办优秀 AI 案例。
2. 入选教育部 10 大典型思政案例。
3. 已在杭州钱塘新区产业发展集团有限公司投入使用。
4. 已在杭州电子科技大学投入使用。
5. 形成了可复用的企业级 Agent 能力底座，支持多业务域（写作、医疗、养老、股票、绘图等）快速扩展。

可量化产出：
1. 日访问量13万+ 。
2. 20+ MCP 工具服务和 100+ Skills 接入（检索、联网、文生图/视频、OCR、学术检索、沙箱执行等）。
3. 12 组 Dubbo Facade 业务接口域（会话、消息、知识库、异步任务、PPT 等）。
4. 统一流式调用链覆盖 10+ 阶段（预处理、审核、路由、RAG、联网、附件解析、工具调用、后处理等），并支持阶段事件回传。
5. 工具调用具备心跳、超时、并发上限与中断恢复机制；工具循环设置最大 5 轮防失控。
6. 会话记忆机制落地：长期记忆支持主题化索引与异步“dream update”，短期记忆支持历史消息/附件/工具消息增量裁剪。
7. 知识库链路完成“两阶段异步化”：预解析（文本提取/清洗/切分）+ 向量化入库（分片处理 + 进度回传 + 失败回滚）。
8. 多模态能力落地：文本解析、OCR、图像理解、视频理解与向量检索联动，支持精确内容增强。
9. 音频能力落地：支持语音输入转写（STT）与语音播报（TTS）双向链路。
10. 安全治理落地：请求/响应双向内容审核、风险标签沉淀与消息统计分析（按天、时段、标签、审核结果等）。
